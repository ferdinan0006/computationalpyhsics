# Penning Trap Simulation
This repository contains the code for Project 3 in the course FYS3150/FYS4150 at the University of Oslo. The project is developed by:

- Johannes Schäfers
- Ferdinand Nilius
- Michał Kiedrzyński

In this project we numerically study Penning traps with different numbers of charged particles stored inside of them. This is done using both Runge-Kutta-4 and forward Euler as numerical schemes. The computations are implemented in C++, while Python scripts are used for visualizing the results.

## Repository structure
The repository is organised into subdirectories as follows:

```
├── code/
│   ├── lib/
│   │   ├── include/lib/
│   │   │   ├── Particle.hpp
│   │   │   ├── PenningTrap.hpp
│   │   │   ├── PenningTrapPerturbed.hpp
│   │   │   └── Solvers.hpp
│   │   └── src
│   │       ├── Particle.cpp
│   │       ├── PenningTrap.cpp
│   │       ├── PenningTrapPerturbed.cpp
│   │       └── Solvers.cpp
│   ├── tasks
│   |   ├── include/tasks/
│   |   │   ├── Task8.hpp
│   |   │   └── Task9.hpp
│   |   └── src
│   |       ├── Task8.cpp
│   |       └── Task9.cpp
│   └── main.cpp
├── python/
│   └── plot.py
│   └── format_data.py
│   └── plotting_funcs.py
├── data/
│   └── One file per simulated particle (format: x, y, z, v_x, v_y, v_z, t)
├── figures/ 
│   └── Animations
└── README.md
```

- `code/` contains the C++ code, with `lib/` and `tasks/` subdirectories containing library and execution code respectively. These follow the include/src file organisation scheme. Top-level `code/main.cpp` is responsible for calling task methods.
- `python/` contains the script used for visualizing and plotting
- `data/` contains the output data generated by the C++ scripts
- `figures/` contains the figures generated by the python script

Requirements
- The C++ code requires cmake, a compiler supporting C++20, and the availability of Armadillo.
- The Python scripts require Python 3 and the packages NumPy and Matplotlib.

## Building and running the code
To build the project, while in the `Project_3` directory, run the command:

```bash
cmake -B build -S . -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

This will both configure and build the C++ program, create a python virtual environment (if not already present), and install required python packages.

To run the compiled C++ program, execute:
```bash
./build/PenningTrap 
```

The generated data is stored in the data/ directory. For every simulated particle one file will be created.

## Plotting
Generate the plots with:

```bash
./.venv/bin/python3 python/plot.py
```
or on Windows:
```bash
./.venv/Scripts/python3 python/plot.py
```

The corresponding files are automatically stored in the figures/ directory.
In addition to the plots displayed in the report, selected results are animated in a gif in the figures / Animations / directory. These are not automatically generated as animations are computationally expensive, if you do want to recreate them remove the comments from the commented out code in the file / python / plot.py.
